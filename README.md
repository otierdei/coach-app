# Oti Hybrid Coach (PWA)

Static web app for GitHub Pages, generated from the claude.ai artifact with `tools/build_from_v67.py`.
Backend: a Google Apps Script web app in the owner's Google account. Data lives in the owner's Google Drive folder "Coach Data".
No personal data is stored in this repository; the backend URL and secret key are stored only on each device (Setup, gear icon).

Rebuild: `python3 tools/build_from_v67.py <artifact.html> .`
