# Exercise figures (v3, 23.10.2026)

- `body.json`: body mesh, 21 bone rig, skin weights and muscle regions. Built from the MakeHuman base mesh, default rig and targets (released as CC0 by the MakeHuman team, Data Collection AB, September 2020) with an athletic male shape. Builder script kept outside the repo (build.py).
- `fig3.js`: skinning, posing (bone directions plus two bone IK for hands and feet), colours (white body, working muscles red, contour lines between muscles).
- `ex3.js`: the exercises: key poses, props, cues in English and German.
- `three-r149.min.js`: three.js r149, MIT licence (see THREE-LICENSE.txt).

Everything here loads only when a figure is opened in the training view.
